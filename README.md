"05 / DEVELOPMENT PHILOSOPHY"

<div align="center">"Learn → Build → Break → Understand → Rebuild"

</div>I don't believe every project needs to be perfect.

Sometimes the best way to understand something is to build it badly first.

Then:

Find the problem.
       ↓
Understand the cause.
       ↓
Fix the architecture.
       ↓
Try again.
       ↓
Make it better.

Every broken build is another lesson.
